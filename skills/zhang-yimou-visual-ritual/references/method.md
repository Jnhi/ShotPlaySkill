# 张艺谋式视觉仪式方法

Use when the scene needs symbolic power, color discipline, folk texture, ceremony, or strong visual concept.

## Core

**颜色不是装饰，是命运；仪式不是排场，是压迫。**

## Techniques

- Assign color by power, desire, shame, danger, memory, or sacrifice.
- Let the color arc change with the story: pure -> stained, hidden -> public, warm -> drained.
- Use repeated gestures as social machinery.
- Make crowds graphic: rows, circles, diagonal lines, processions, gates, courtyards.
- Use folk materials: cloth, paper, grain, earth, fire, water, drum, wall, costume, field.
- Let one image carry the theme before anyone explains it.

## AI Short Drama Use

Strong for title images, episode climaxes, ritual punishments, public reveals, wedding/funeral/festival scenes, village/family pressure, and symbolic vertical-video posters.

# 周星驰式启发的喜剧桥段机制

Use this file when the task needs stronger comedy. Treat it as a gag-construction checklist, not a style imitation sheet. Do not copy existing jokes, lines, or iconic scenes.

## 1. Comedy Density Target

For a 10-minute short:

- One clear comic beat every 15-25 seconds in the first 3 minutes.
- One major set piece every 2-3 minutes.
- Each set piece needs at least 3 escalations and 1 emotional reversal.
- Dialogue jokes alone are not enough. At least half the comedy should be visible without subtitles: prop, body, spatial relation, facial timing, reveal, or cut.

If the script feels "AI," it often lacks visible business. Add actions before adding clever lines.

## 2. Gag Machine

Build each gag from four parts:

```text
Pressure: what the character desperately needs now.
Wrong method: the sincere but absurd way they try to solve it.
Escalation: the world rewards/punishes the wrong method in a bigger way.
Turn: the gag reveals pain, dignity, romance, or theme.
```

Bad gag: random strange behavior.
Usable gag: wrong behavior that is emotionally logical.

## 3. Seven Reliable Mechanisms

### Status Ceremony

A low-status person treats a tiny task like a national ceremony.

Use for: repairman, extra, waiter, security guard, delivery worker, intern, failed actor.

Pattern:

```text
Tiny task -> solemn ritual -> others mock it -> ritual accidentally works -> status flips.
```

### Misread Authority

Someone misunderstands a fake, tiny, or accidental symbol as official power.

Pattern:

```text
Wrong badge / uniform / title / prop -> people obey -> protagonist trapped by fake status -> real test arrives.
```

### Prop Logic

A cheap object is treated as a high-tech or sacred device.

Examples of object types:

- broken umbrella, mop, delivery box, rice cooker, fake trophy, toy microphone, flashlight, traffic cone, shoe, plastic bag.

Pattern:

```text
Object named grandly -> used practically -> fails in a funny way -> succeeds emotionally.
```

### Repetition With Mutation

Repeat the same action three times, but change scale and meaning.

Pattern:

```text
1st: small failure.
2nd: larger public embarrassment.
3rd: same failure becomes useful or heroic.
```

### Delayed Reveal

Show the reaction before showing the ridiculous cause.

Pattern:

```text
Everyone freezes -> protagonist acts serious -> hold silence -> reveal tiny/absurd source -> cut on reaction.
```

### Body Betrays The Heart

The character says one thing, but the body performs the opposite.

Pattern:

```text
Claims confidence -> foot shakes / hand salutes wrong / smile collapses / object sticks / body overcommits.
```

### Laugh-To-Hurt Turn

The audience laughs first, then realizes why the behavior matters.

Pattern:

```text
Ridiculous habit -> repeated as joke -> exposed as survival method, love, shame, or old wound.
```

## 4. Dialogue Rules

Keep dialogue simple, literal, and pressure-based:

- Let characters misunderstand common words.
- Let characters answer the wrong question with total confidence.
- Let a pompous title collide with a cheap reality.
- Use short callback lines. Do not explain the joke after it lands.
- Put the punch on the last word when possible, then cut.

Avoid internet-style one-liners. The joke should belong to this body, this prop, this situation.

## 5. Scene Comedy Pass

Before drafting a scene, fill this:

```text
Character pressure:
Humiliation:
Main prop:
Fake status / wrong identity:
Beat 1:
Beat 2 escalation:
Beat 3 escalation:
Public embarrassment:
Unexpected usefulness:
Laugh-to-hurt turn:
Cut point:
Callback later:
```

## 6. Rewrite Checklist

When a scene feels flat:

- Add one prop that can be named grandly and used badly.
- Add one public witness who misunderstands the situation.
- Add one body problem the character cannot hide.
- Add one repetition that returns later as a heroic solution.
- Add one silence before the reveal.
- Remove one explanatory line after the joke.
- End the scene on a reaction, not a moral.

# Director Distillation Workflow

Use this to expand any profile into a deeper standalone skill.

## Step 1: Source Pack

Collect:

- 5-8 representative works.
- 3-5 interviews, essays, production reports, or official profiles.
- 3 scene studies with time-coded observations.
- Repeated craft patterns across at least 3 works.

## Step 2: Distill Into Usable Craft

Do not write biography first. Extract:

```text
Core thesis:
Story engine:
Character engine:
Scene mechanics:
Camera/light/composition:
Rhythm/editing:
Genre rules:
Common objects/spaces:
Failure modes:
Prompt templates:
```

## Step 3: Make It Useful For AI Short Drama

Translate the director into short-form decisions:

- First 5 seconds.
- 30-second beat.
- 1-minute scene.
- 3-episode mini-arc.
- Image prompt.
- Video prompt.
- Rewrite checklist.

## Step 4: Avoid Fake Imitation

Never answer as the director. Never claim private intent. Avoid copying exact scenes, dialogue, costumes, props, or iconic shots unless the task is explicit analysis or homage.

Use language like:

```text
Public-source-inspired craft lens.
Observable method.
Distilled directing principles.
```

# Source Backbone

This is the initial research spine for the 50-director library. Expand each director with deeper source packs before creating a standalone focused skill.

## Reliable Source Types

- Official filmmaker/academy/festival profiles: Oscars, Cannes, BFI, DGA, Criterion, studio archives.
- Long interviews: DGA Quarterly, Film Comment, BFI, Criterion, NPR, The Talks, Filmmaker Magazine.
- Production reports: American Cinematographer, ASC, making-of books, verified production interviews.
- Scene essays: Criterion Current, BFI features, academic film journals.

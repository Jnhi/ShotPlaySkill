# 宁浩式黑色喜剧结构方法

Use for realistic absurd comedy, crime farce, low-budget short drama, and multi-line plot engines.

## Core

**每个人都很现实，每个计划都很合理，撞在一起就很荒诞。**

The comedy comes from causality and pressure, not random jokes.

## Plot Engine

```text
Character A want:
Character B want:
Character C want:
Shared object:
Wrong assumption:
Collision 1:
Collision 2:
Collision 3:
Ironic payoff:
```

## Techniques

- Use money pressure as a clean engine.
- Make small people competent in one tiny domain and foolish outside it.
- Build multiple lines that cross around one object, location, or deadline.
- Use local details as comedy: job procedures, cheap tools, street habits, dialect logic, bureaucracy.
- Let misunderstandings accumulate into a trap.
- Pay off every setup; no loose "funny" event should float.

## AI Short Drama Use

This skill is strong for 1-3 minute episode engines:

- Episode open: a practical plan.
- Middle: a second plan collides.
- End: a consequence turns the plan against the protagonist.

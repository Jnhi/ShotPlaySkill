# L4 · 媒介模式 — 电视剧（横屏 16:9）

```
画幅：16:9｜单集：45分钟左右｜季：12-40集｜观看场景：客厅/平板，半专注+可能倍速
本质：电视剧是"陪伴媒介"——观众和角色长期共处。电影靠冲击，短剧靠钩子，电视剧靠**关系**。
```

> **切换思维开关：观众不是来看一个故事，是来"见这些人"。** 角色魅力>单集情节。镜头语言为"让观众更懂这些人"服务。

---

## 一、结构：集结构 + 线编织 + 季弧

**单集四段式（45min）**：

```
冷开场(0-3min)   本集钩子或上集扣子承接 → 片头
第一段(3-15min)  A线推进 + B线引入
第二段(15-30min) A/B线交织升级 → 中段小高潮(out点)
第三段(30-43min) 汇合与本集解决（解决本集问题，留下季问题）
集尾(43-45min)   钩子：新信息/新威胁 → 让人按"下一集"
```

**线编织规则**：A线（本集主情节）+ B线（角色关系/副线）+ C线（季弧线，每集只推一格）。三线每集都要碰一次——交叉蒙太奇（L1律十）是电视剧的主语法。

**季弧**：季首立问题 → 每集解决小问题推进大问题 → 季中(第6-7集)大反转 → 季末解决并立下季钩子。重要角色每季一条完整变化弧。

## 二、电视剧镜头语法

| 维度 | 规则 | 备注 |
|------|------|------|
| 主力景别 | MS/MCU——"对话景别" | 电视剧是对白驱动的媒介，景别服务台词 |
| 正反打 | 效率语法：过肩MCU为默认 | 但重场戏必须打破默认（推近到CU/同框/长镜）否则全剧一个味 |
| 多人调度 | 群戏构图是电视剧基本功：餐桌/会议/家庭场景的视线管理 | 谁看谁=权力关系图 |
| 重复场景 | 同一场景（家/办公室）反复出现 → 建立2-3个标准机位做"空间锚"，观众瞬间认出 | 关键剧情时打破标准机位=信号：今天不一样 |
| 倍速防御 | 关键信息必须画面+台词双通道（观众可能1.5x在听）| 纯视觉伏笔要重复2次 |

## 三、电视剧专属武器

- **空间锚定**：标准机位库（每个常用场景3机位）——既是效率工具，也是"打破时的戏剧信号"（L1律二破律"重复"的应用）
- **角色镜头签名**：每个主角配一套专属镜头习惯（某人总是被门框框住/某人总在画面边缘）——观众无意识积累认知，关键集打破=人物弧光的视觉化
- **冷开场库**：日常型（陪伴感）/悬念型（拉人）/承接型（连续剧情）三类轮换，连续3集同类型=疲劳
- **out点**（中段小高潮）：源自广告位时代，流媒体时代仍有效——45分钟注意力需要中点重启

## 四、电视剧声音特化（基于 L3）

- **对白主导**：台词轨是第一轨，混音上对白永远清晰可懂（半专注观看场景）
- 台词信息冗余度高于电影：重要信息允许"说一次+做一次"双确认
- 声底是陪伴感来源：家的声底（冰箱嗡鸣/挂钟）每集一致，观众产生"回家感"——**声底锚定与空间锚定同步设计**
- 无BGM红线照常

## 五、AI 生成接口（与 L2）

同受 L2 约束。电视剧特有：标准机位库 = 资产锁定的延伸——每个常用场景的3个标准机位各做一张定妆参考图入 refs，跨集复用，一致性成本最低。这是电视剧相对短剧/电影的 AI 生成优势：场景复用率最高。

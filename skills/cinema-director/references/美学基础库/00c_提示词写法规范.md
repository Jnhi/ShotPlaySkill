# 02 · 提示词写法规范 — 美学落地生图(超级美学系统·产出端)

> **这是把"美学"翻译成"提示词"的标准流程。** 拆解拿到的美学(色/光/构/质感/符号),怎么组装成一条能直接喂 Midjourney / Seedance / Flux 的提示词——本文件规定死。
> 与净帧skill同源:净帧管"反脏纪律",本规范管"从美学库取料+组装+平台适配"。冲突时纪律听净帧。

---

## 一、七段式骨架(一切提示词的最终形态,承净帧)

```
① 风格锁定句     渲染域(A写实/B动漫/C_3DCG)+ 流派 + 画幅   ← 防杂交,第一句
② 主体+情绪动词   没有情绪动词的图是素材图
③ 环境           ≤3件点名道具,其余交给"虚/空/暗"
④ 光             主光源(位置+方向+衰减)+光比+辅光让路      ← 取料自 10光影库
⑤ 镜头/画面语言   景别/构图法/机位/焦距/景深                ← 取料自 12构图库
⑥ 色彩预算       1主+1辅+1点缀,饱和度点名给谁              ← 取料自 11色彩库
⑦ 质感收尾+负面   质感钥匙(13库)+ 通用负面 + 族专属负面
```

## 二、取料顺序(从超级美学系统各库调钥匙,按此序组装)

**先定域,再定型,后填料**:

1. **拨渲染域**(21总开关)→ 决定①句 + 走 A/B/C 哪套质感语言(13质感库)。
2. **定类型/风格**(16类型片库 / 15国别库 / 军火库导演skill)→ 拿整套"配方"(色光构一次到位)。
3. **填四支柱料**:
   - ④光 ← 10光影库(选布光流派+光质+光方向+色温)
   - ⑤构 ← 12构图库(选构图法+景别+机位+焦距)
   - ⑥色 ← 11色彩库(选配色结构+三色hex+饱和度)
   - 符号 ← 14符号词典(可选,埋1个母题)
4. **质感收尾** ← 13质感媒介库(颗粒/CG钥匙/去假十律)。
5. **服化道** ← 18服化道库(角色图必走)。

> **省算力心法**:不必每次翻全库。开一个项目先做一页"项目美学宪法"(锁定域+类型配方+三色hex+光影钥匙+负面包),全项目照抄,只微调②③主体环境——这就是"指针节省算力"的落地。

## 三、四风格族锁定句(①句照抄)

| 族 | ①锁定句 | 关键英文钥匙 |
|---|---|---|
| A写实电影 | 电影剧照质感,实拍摄影,+胶片/数码倾向 | photorealistic, live-action, cinematic, film still |
| B_2D动画 | 二维手绘动画,XX上色风格(赛璐璐/厚涂/水彩) | 2D anime, cel animation, hand-drawn |
| C_3DCG | 电影级三维渲染,+写实CG/三渲二 | 3D CG render, cinematic / toon-shaded |
| D插画概念 | 数字厚涂概念设计 / 水彩插画 / 扁平矢量 | digital painting concept art / watercolor illustration |

## 四、去假十律(C域强制,防AI假感·详见24§二B)

CG提示词必查:①光晕只给最亮1-2处 ②材质写使用史(磨损/污渍)③接触阴影 ④反射破碎 ⑤空气分层微尘 ⑥统一低饱和调色 ⑦陈设生活痕迹 ⑧比例参照 ⑨不完美对齐 ⑩去假三问(哪里脏/谁用过/站稳没)。

## 五、负面词组装(⑦段)

```
通用基础包(必带):字幕,画面内任何文字,水印,logo,细节堆砌,多光源打架,死黑噪点,高光剪切,构图无焦点
+ 族专属包:
  A:三维渲染感,动漫风,磨皮,塑料皮肤,HDR过度,全图锐利
  B:三维渲染,照片写实背景,伪3D高光,真实皮肤纹理,帧率过顺
  C:塑料质感,恐怖谷,游戏过场感,全图泛光,出厂全新材质,无接触阴影悬浮感,均匀反光,糖果色高饱和,空气真空感
+ 项目专属禁色(如科幻神话项目示例禁:好莱坞青橙,荧光粉紫,日式和风符号)
```

## 六、平台适配(同一美学,不同平台的落地差异)

| 平台 | 语言习惯 | 关键参数/写法 |
|---|---|---|
| **Midjourney v8.1** | 吃视觉密度词,不吃"必须/只许"指令句;负面走 `--no` | `--ar` 画幅 / `--style raw` 去美化提服从 / `--s` 0-1000 风格化 / `--sref [图URL]` 锁全剧色调 / `--oref [图URL] --ow` 锁角色脸;默认HD 2K |
| **Seedance(视频)** | 吃时间码分镜+镜头动词;七层提示词 | 六步公式(主体+动作+环境+镜头+风格+约束),前20-30词权重最高;无BGM三件套负面;`camera_fixed`/`return_last_frame`(2.5) |
| **Flux/SD** | 吃标签+权重 | 括号加权,负面提示词栏分离 |

> **锁色/锁脸铁律(MJ线)**:世界观定调帧过检后 → 全项目挂 `--sref` 锁色彩宪法;角色定妆过检后 → 挂 `--oref --ow 300-500` 锁脸,这是MJ版的"色彩宪法+脸锚",比纯文字狠得多。

## 七、出图后自检(接净帧六查+去假三问)

1. 光有主?2. 眼有落点(≤2)?3. 风格一口纯?4. 暗部干净?5. 焦点有虚实?6. 颜色有预算?
C域加:哪里脏?谁用过?站稳没?
过不了 → 按"哪段提示词、怎么改"开处方(净帧质检模板)。

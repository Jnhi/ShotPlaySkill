# 美学基础库 · 01 色彩体系

> **用法**:写生图提示词时,色彩字段从本库点菜——先选和谐结构,再从大师档案抄"可偷的招",最后用第三节的饱和度预算做审查。
> 接线:净帧七段式**⑥色彩预算段**从这里取写法;绮罗"金青对冲/艳在光泽不在色块"是本库的女频精选应用。
> 铁律:**每个画面必须能一句话答出"这画面是什么颜色的"——答不出=多色打架=废。**
> hex 为剧照取色近似值,做提示词参考足够。来源:StudioBinder/CineD/Priceonomics/Color Culture 等10+信源实爬,2026-07建库。

## 一、五大和谐结构(先选结构,再填颜色)

| 结构 | 电影实证 | 高级用法 | 一句话纪律 |
|---|---|---|---|
| **互补色** | 《狂暴之路》橙青、《天使爱美丽》红绿 | 橙青泛滥病根:数字调色流水线+肤色永远在橙区。高级解法:**按场景整块切换**(日橙夜青),不同框搅拌;或换一对互补(红绿) | 互补不同框糊,分区块统治 |
| **分裂互补** | 《阅后即焚》 | 主色+补色两侧邻居,保留冷暖对抗但削掉火药味,天然产生"一主两辅" | 比正互补更不容易俗 |
| **类比色** | 《美国骗局》红橙棕黄、《人类之子》灰青褐 | 零内耗高统一,氛围片安全解 | 色相帮不上忙,**必须靠明度和质感拉层次** |
| **三角色** | 《狂人皮埃罗》《超人》 | 电影里最少用——三纯色同场极易卡通化 | **用三角必压饱和度**;高饱和三角只有韦斯·安德森靠极端秩序镇得住 |
| **单色统治** | 《黑客帝国》绿、《英雄》分章 | 颜色升格为空间/真伪/视点的标签 | 单色内部靠明度+材质分层,配一个小面积异色 |

## 二、大师配色档案(14将)

模板:**色板hex → 策略 → 可偷的招(提示词直接抄)**

### ① 王家卫《花样年华》
- 色板:`#8C1F28` 深胭脂红 / `#CC0000` 正红 / `#D58D29` 昏黄钨丝 / `#F1C232` 芥末金 / `#3B4A3F` 墨绿 / `#1A1212` 近黑褐
- 策略:红黑统治全片,压抑的欲望外包给颜色;绿蓝穿插处即婚姻崩坏处。
- 偷:「深夜狭窄走廊,墙面暗红与墨绿剥落,唯一光源是头顶昏黄钨丝灯,人物旗袍的酒红在阴影里只亮出一条边,暗部占画面七成,烟雾轻微」

### ② 张艺谋《英雄》——单色统治公式
- 色板:红章 `#B02418`+`#D4A017` / 蓝章 `#4A6E8A`+`#7FA9C4` / 绿章 `#7FA37A` / 白章 `#E5E1DA` / 秦宫黑 `#1C1C1E`+一点朱红
- 策略:一个叙事版本一种单色,颜色=视点与真伪标签。
- 偷:「全画面被单一朱红统治:红衣、红纱、红墙,仅以明度区分前后景,漫天黄叶做唯一异色点缀,占比不超一成」
- **公式:一个色相 + 材质分层 + 一个小面积异色**

### ③ Roger Deakins《银翼杀手2049》
- 色板:橙雾 `#D96C2C`/`#E8853A` / 青灰雨 `#37474F`/`#5C6B73` / 华莱士金 `#C9922A` / 农场惨白 `#E8E4DA` / Joi霓虹粉蓝紫 `#7B68EE`
- 策略:一个地理空间一种统治色,雾/雨/尘做天然柔光箱。
- 偷:「浓橙色沙尘雾统治整个画面,能见度低,人物只是逆光剪影,无任何第二色相;雾即光源」/「青灰雨夜,巨型全息广告的粉蓝色是画面唯一高饱和,并**真实地照亮人物半边脸**」
- **纪律:霓虹必须参与照明,不能只是背景贴纸。**

### ④ Wes Anderson《布达佩斯大饭店》
- 色板:`#F4A8B9` 饭店粉 / `#8B5FBF` 门童紫 / `#D9381E` 电梯红 / `#A4D8FF` 粉蓝 / `#F9D1BC` 奶油肤
- 策略:糖果色×黑暗主题反差;高饱和靠**色相数量严格配给+对称秩序**镇压。
- 偷:「糖果粉色建筑立面严格居中对称,门童制服为饱和紫色,像限定三色的复古明信片,饱和度高但色相总数不超过四种」

### ⑤ 新海诚《你的名字。》
- 色板:天青 `#87CEEB` / 黄昏金橙 `#F7B267` / 黄昏紫 `#6C5B9E` / 星蓝 `#2B5F9E` / 云缘白粉 `#FFE8D6`
- 策略:magic hour 定为情感高潮专属色;**高饱和只给天空**,地面中饱和。
- 偷:「黄昏magic hour,天空从金橙渐变到紫再到深蓝三段式,云被夕阳镶粉边,地面景物整体压成蓝紫剪影,唯一暖光是天空的反光;空气中有可见光粒子」

### ⑥ 《燃烧女子的肖像》
- 色板:海岸青灰 `#9FB4B8` / 冷蓝海 `#35526B` / 绿裙 `#2E5940` / 红裙 `#A33B2A` / 烛光米金 `#E6C89A` / 亚麻白 `#E6DCC3`
- 策略:冷调低饱和油画底,让三件裙子成为全片唯一的色彩事件;两种色温之外无第三光源。
- 偷:「阴天海岸,整体青灰低饱和如18世纪油画,人物一袭祖母绿长裙是全画面唯一饱和色;光线全部柔和漫射,无硬阴影,皮肤油画缎面质感」

### ⑦ 《疯狂的麦克斯:狂暴之路》
- 色板:日戏琥珀 `#E8720C`/铁锈 `#C1440E` / 过曝白天空 `#F5EFE6` / 夜戏钢青 `#1B4F5C`/`#27607A`
- 策略:日=纯琥珀、夜=整体染蓝,分时段单色统治;高饱和靠**颗粒与污渍**兜住不塑料。
- 偷:「沙漠日景:天空过曝接近白,沙地饱和琥珀橙,车辆人物如白纸上的墨点;画面有粗粝颗粒与扬尘,拒绝干净塑料感」

### ⑧ Hoyte van Hoytema《沙丘》《奥本海默》
- 色板:沙金 `#C8A97E` / 尘灰 `#8A8578` / 哈克南漆黑 `#141414` / 钨丝暖肤 `#D9A06F` / 会议室灰蓝 `#6E7B8A`
- 策略:禁欲式"环境单色+自然光",全靠明度、体量、尺度撑画面;《奥本海默》彩色=主观/黑白=客观。
- 偷:「大漠场景整体限制在沙金与尘灰两个相邻色内,无任何冷色;人物微小,置于巨大负空间中,顶部硬质自然光」

### ⑨ 维米尔——室内人像万能公式
- 色板:群青 `#34568B` / 铅锡黄 `#E1B94C` / 暖灰墙 `#D9CBB5` / 赭土 `#8A6D4B`
- 策略:单一侧窗光+蓝黄互补;贵的群青只给主体衣饰。
- 偷:「室内左侧单一窗光,柔和漫射,墙面含灰暖白;人物上衣群青蓝与头巾铅锡黄构成全画面仅有的两个饱和色,其余皆土色系」
- **公式:窗光 + 灰底 + 两颗宝石色**

### ⑩ 卡拉瓦乔——黑暗主义
- 色板:纯黑背景 `#0D0A08` / 琥珀肤 `#C68E5C` / 血红 `#7A1F1F` / 亚麻白 `#D8CFC0`
- 策略:tenebrism,背景沉黑,单束高侧位硬光只照脸、手、关键道具。《教父》顶光黑眼窝是它徒孙。
- 偷:「背景完全沉入黑色,单束高侧位硬光只照亮人物面部与手,明暗交界锐利,暗部不留细节;全画面仅肤色、暗红衣物与黑三种颜色」

### ⑪ 爱德华·霍普——城市孤独
- 色板:夜绿荫 `#26403C` / 日光奶黄 `#E8D8A0` / 砖红 `#9C4A31` / 病绿灯 `#9DB89A` / 木褐 `#5C4033`
- 策略:暖光源被冷色包围,人物被光"隔离"在色块里;"窗内暖黄/窗外夜青"母题源头。
- 偷:「深夜街角,街道整体墨绿青冷,唯一暖色是玻璃窗内餐馆的黄光,人物孤坐光池之中;色块边界干净,光影锐利几何斜切」

### ⑫ 莫兰迪——灰调为何高级
- 色板:灰粉 `#C5AFA4` / 灰绿 `#A3AD9C` / 驼 `#B8A183` / 雾蓝 `#9DA8B0` / 米灰 `#D9D3C7`
- 原理三层:各低饱和色互相制约=视觉平衡;低饱和=情绪输出少=冷静感;灰调已被驯化为"贵"的符号(《延禧攻略》实证)。
- 偷:「全画面莫兰迪灰调:灰粉、灰绿、驼色、雾蓝,每种颜色都像掺了同一勺灰,无任何纯色;颜色间只有微妙深浅差,质感如哑光陶罐」
- **命门:必须靠质感和光影补层次,否则=灰蒙蒙的脏。**

### ⑬ 奉俊昊《寄生虫》——色彩=海拔=阶级
- 色板:朴宅暖木金 `#C7A97B`+庭院绿 `#57704E` / 半地下青灰 `#5E6B63`+荧光病绿 `#4A5D4E`+洪水浊褐 `#6B5D48`
- 策略:同一部片两套光源两套色温,阶级不用台词说;剧情下坠画面随之滑向单色浊调。
- 偷:「豪宅客厅,整面落地窗自然光洒在暖木色与庭院绿上,通透干净」vs「半地下室,惨白荧光灯混着街口漏进的一线冷光,整体青灰,墙面有潮渍」

### ⑭ 《爱乐之城》——色彩弧线教科书
- 色板:Mia蓝 `#1E5AA8` / Seb红 `#C0392B` / 试镜黄裙 `#F2C230` / 和声紫 `#4B3B8F` / 暮色洋红 `#B85C8A`
- 策略:蓝=幻想,红=催化,紫(红+蓝)只在两人和谐时出现;服装颜色随情节换挡。
- 偷:「暮色紫蓝天空下,人物一袭正黄色连衣裙起舞,街灯是画面里的暖色点;红蓝双色光从两侧分别打在两人身上,中间交汇为紫」

## 三、色彩的叙事功能

### 1. 色彩弧线(Color Arc)
颜色随剧情系统性变化,"配色"升格为"叙事":《寄生虫》色彩海拔与社会海拔同步;《绝命毒师》服装米色→黑色。
**生图应用:一套组图的提示词要预先写好"第1张什么色→第N张什么色"的弧线,不许每张独立配色。**(接首帧锚定图/海报帧组产出)

### 2. 色温对比叙事
规律:**冷暖不要调匀,要"一边倒+一个缺口"**——环境统一冷,暖只从一个光源漏进来(或反之)。上限两种色温,且各有明确出处(烛光+月光/钨丝+夜青)。

### 3. 饱和度预算(Saturation Budget)
- 原理:**饱和度是注意力货币**。处处高饱和=处处在喊=没有焦点;低饱和让仅有的饱和处成为"情绪事件"。
- 大师的花法:维米尔只给两颗宝石色;《燃烧女子》只给三件裙子;Deakins 只给一块广告;新海诚只给天空。
- 高饱和不是原罪:《狂暴之路》《布达佩斯》成立靠**限制色相数+颗粒/秩序兜底**——预算可以花在饱和度或色相数上,**不能两头挥霍**。

## 四、配色失败模式七宗(病→处方)

| # | 病 | 处方(提示词层面) |
|---|---|---|
| 1 | 橙青糊满,阴影发青高光发橙互相污染 | 按区块/场景分配互补;写「阴影为中性冷灰而非青色」「暖色仅来自XX光源」 |
| 2 | 多色打架,无统治色 | 先声明统治色及占比「整体青灰统治,暖色不超一成」 |
| 3 | 饱和度无预算,全画面都饱和 | 写清「仅XX为饱和色,其余低饱和」 |
| 4 | 假莫兰迪:各色灰得不一致,脏而非雾 | 「同一基底灰+哑光材质+微妙明度差」三件套,缺一即脏 |
| 5 | 霓虹贴纸病:有色光不参与照明 | 任何有色光源必须在皮肤、地面留下反光痕迹 |
| 6 | 多色温打架,光无出处 | 色温上限两种,各有明确来源 |
| 7 | 高饱和+塑料质感 | 高饱和方案必须同时写入颗粒、尘土、材质瑕疵 |

# 01 · 美学拆解SOP — 三遍拆解法(超级美学系统·方法论地基)

> **这是把任何一部作品/一种质感"拆进系统"的标准流程。** 拆一部新片、解剖一张好图、逆向一种质感,都走这套。提炼自《电影镜头美学》课程"三遍看片法"+ 净帧六查 + 四大支柱。
> 产出统一收敛为 §四《美学档案标准模板》,归入 `20_案例拆解库/`,可复用结论回流对应分类库(色→11 / 光→10 / 构→12…)。

---

## 一、三遍拆解法(看片纪律)

| 遍 | 看什么 | 动作 | 产出 |
|---|---|---|---|
| **第一遍** | 看剧情/看感受 | 只感受,不分析。记下"哪一帧让我心动/窒息/不安" | 情绪锚点清单 |
| **第二遍** | 截画面 | 逐帧截图,提主色调、量构图、找光源 | 截图 + 调色板 + 构图标注 |
| **第三遍** | 找规律 | 按四大支柱拆,归纳"只此一家的签名" | 美学档案(§四模板) |

> 口诀:**第一遍只能"感受",第二遍才能"分析",第三遍才能"模仿与实践"。剧情=表层,影像语言=深层。**

## 二、先问三问(拆解的入口,每帧/每场都问)

1. **它让我感觉到什么?**(情绪动词:渴望/危险/孤独/压抑/亢奋/神圣…只选一个)
2. **它为什么让我有这种感觉?**(哪个视觉要素在起作用)
3. **导演用什么影像手段达成?**(具体到色/光/构图/符号/质感的某一招)

答不出第一问=这帧还没看懂;答不出第三问=还没拆到可复用层。

## 三、四大支柱 + 两扩展(逐项拆解清单)

> 电影美学四大支柱(课程定义):**构图 · 色彩 · 光线 · 符号**。本系统扩两项:**质感媒介 · 服化道**。拆解时逐项过。

| 支柱 | 拆解要点 | 深挖去哪个库 |
|---|---|---|
| **① 色彩** | 主/辅/点缀三色(带hex);饱和度明度;冷暖;色彩情绪弧线;单色情感;禁色 | → 11色彩美学库 |
| **② 构图** | 构图法(对称/留白/框架/三角/对角线…);景别;机位角度;焦距;三层纵深 | → 12构图美学库 |
| **③ 光影** | 布光流派(卡拉瓦乔/伦勃朗…);光质(硬/柔);光方向;光比高低调;动机光;色温 | → 10光影美学库 |
| **④ 符号** | 反复出现的物件/动作/空间象征;母题;色彩符号 | → 14符号象征词典 |
| **⑤ 质感媒介** | 胶片/数码/仿胶片/CG/2D/三渲二;颗粒;镜头光学缺陷 | → 13质感媒介库 |
| **⑥ 服化道** | 服装色彩弧线;化妆的身份表达;道具符号与做旧 | → 18服化道美学库 |

## 四、美学档案标准模板(一切拆解的产出格式)

```markdown
# 《作品名》美学档案
## ① 一句话美学签名   （这部片"只此一家"的视觉标识,删掉片名能猜出是它)
## ② 色彩配方          主/辅/点缀(hex+饱和度)+ 禁色 + 情绪弧线
## ③ 镜头与构图        景别偏好/运镜/构图法/机位角度/焦距/画幅
## ④ 光影特征          光质/光比/光方向/布光流派/动机光/色温/时间光
## ⑤ 符号与服化道      反复符号 + 服化道要点(可选)
## ⑥ 可复用"偷师点"3-6招  每招=一句能直接抄进提示词的话(中英),末尾一句"心法"
```

**偷师点纪律**:每招必须"具体到能写进提示词",禁止"增加质感""更有电影感"这类废话;给出中英钥匙。

## 五、拆完回流(闭环)

1. 案例档案存 `20_案例拆解库/《作品名》.md`;
2. 新提炼的可复用手法,回流对应分类库(新配色→11、新布光→10、新构图→12、新符号→14);
3. 若发现全新维度(现有库覆盖不了),在 00总索引 登记新库;
4. 军火库索引与本SOP双向登记,防孤儿档案。

# 90 · 实战手册(产线 Lite)— 从方法论到能开机

> 前面的工艺文件教你"怎么想",本手册教你"怎么不翻车"。这是完整版生产线的够用版:照做能稳定产出制作精良的成片;工业化的逐模型红线库、六维QA评分器、调度图、表情库属 Pro 版。

## 一、生成红线(通用版·跨模型)

任何视频生成模型,以下八条先守住,能避开 80% 的翻车:

1. **单镜单一运动方向**——一颗镜头只写一种镜头运动;"推近同时横移再摇"=必糊。要复合运动就拆镜。
2. **单段 5–15s**——超过就拆段;短剧节奏下每镜 1.5–4s 为主食。
3. **不写镜头参数数值**——"85mm、f/2.8、ISO400"这类数字模型不认还添乱;写效果:"浅景深,背景虚化,主体锐利"。
4. **光线必须写详细**——光源是什么+从哪来+往哪衰减(动机光,10号文件铁律)。光写得越具体,画面越不像AI。
5. **一镜一拍一变化**——一颗镜头里只安排一个情绪/动作变化;要"平静→震惊→愤怒"就拆两镜。
6. **台词预算**——15s 段落只放一个中文短句(≤15字);台词写明语气。
7. **速度词慎用**——"快速/极速"易触发运动模糊或跳帧,用物理细节写速度("三步并作两步""衣袂扫过镜头")。
8. **负面提示词≥5项**——至少含:与画幅相反的构图、背景音乐、配乐,再按场景补(变形/多余手指/滑步/悬浮感等)。

## 二、去AI感三方(画面为什么假)

| 病灶 | 病因 | 药方 |
|---|---|---|
| 人物与背景分离(贴片感) | 滥写"背景虚化",人物零环境交互 | 每镜写≥1处环境交互:脚踩起尘、衣角扫过桌沿、影子落在墙上 |
| 动作僵硬(木偶感) | 只写姿态不写过程 | 写过程量:"缓缓抬手"→"借转身的惯性抬手,指尖先动" |
| 画面太干净(渲染感) | 空气里没有介质 | 空气三件套:光(丁达尔/尘埃颗粒)+声底(环境声)+介质(雾/雨/蒸汽/飞絮),按场景选1-2样 |

## 三、图先行与角色一致性(治变脸)

**能图生视频就不要文生视频。** 流程:

1. **先出首帧图**——按七段式生图规范(美学基础库/00c)生成该镜首帧,静态审过(构图/光影/角色像不像)再进视频生成。首帧不合格,视频必不合格;首帧的表情就是这镜的表情,I2V阶段救不回中性脸。
2. **角色身份描述块逐字复用**——同一角色在所有镜头的提示词里,外观描述一字不差地复制粘贴(禁同义词替换:"玄色劲装"不许时而写成"黑色武服")。给每个主角建一个身份块存档,用时粘贴。
3. **参考图锁脸**——支持参考图的模型,同一角色全程用同一张定妆参考图;用参考图时提示词不再描述长相,只写景别+动作+服装。
4. **首尾帧衔接**——段尾状态声明(六段式⚡三件套之一)=下段首帧的生成依据;跨段动作必须"段尾什么姿势,下段开头就什么姿势"(详见25号文件)。
5. **一致性约束句**——每条提示词【角色/主体设定】尾部加:"保持五官、发型、服装不变;同一角色;面部清晰不变形"。

## 四、六段式硬性规则(十条,全过才算完)

1. 每段提示词总字数≤800;六个【】板块缺一不可,顺序不可调,不许改名/合并/自创板块
2. 画幅声明全局统一(默认9:16竖屏,横屏项目全链改16:9),【负面提示词】含相反画幅
3. 【核心风格基调】必含:文化风格+情绪词+美学流派+沉浸氛围+电影级镜头语言+渲染域声明(21号文件三选一)+画幅
4. 【画面质感参数】必含:材质+光线(动机+衰减)+氛围+参考影片
5. 【角色/主体设定】每主体必含:身份+神情+动作+外观细节;群像注明"不给清晰正脸特写"
6. 【镜头与分镜脚本】按时间线逐镜写(0-Xs起止),场景总设定在前;台词/音效/环境声写在每镜末尾括号内
7. 【镜头与分镜脚本】末尾必带⚡三件套:景别交替检查/动静匹配检查/段尾状态声明
8. 【技术与输出参数】:4K/30fps/画幅/时长≤15s/运镜逐镜列出
9. 【负面提示词】≥5项,必含相反画幅+"背景音乐,配乐"
10. 全文遵守§一生成红线(单镜单向/无参数数值/光线详细)

**分段边界四检**(分镜表阶段):每段累计≤15s ✅ 相邻镜头景别不重复 ✅ 相邻镜头动静匹配(动接动静接静) ✅ 段尾动作=下段开头动作 ✅

## 五、交付前快检(六问,任一不过重做)

```
□ 1. 角色一致?——同一角色各镜头五官/发型/服装可辨认为同一人(身份块逐字复用了吗)
□ 2. 光影有源?——每束光答得出"从哪来、往哪衰减"(无源之光=AI感)
□ 3. 物理可信?——脚踩实地不滑步、接触有阴影、布料头发有重量
□ 4. 环境活着?——有环境交互+空气介质,不是绿幕贴片(§二三方)
□ 5. 声音三轨?——台词/音效/环境声齐,且负面词禁了BGM
□ 6. 海报帧在哪?——本场至少一帧值得截图;指不出来=美学没做够(11§六)
```

## 六、最小工作流(一集短剧从零到成片)

```
① 立项:21拨渲染域 → 11七步法造美学圣经 → 13定母题视点 → 04短剧语法
② 每集:13想什么 → 29调度图(每场先画:站位/机位/灯位,过五检) → 12拆分镜(过四检) → 10/11抛光 → 六段式提示词(过十条)
③ 生成:先出各镜首帧图(§三) → 审图 → I2V逐段生成 → 过§五快检
④ 不合格:对照§一红线和§二三方找病因,改提示词重生成(改一处测一处)
⑤ 剪辑:按25号文件衔接纪律拼段,后期统一调色降饱和、加轻微颗粒压渲染感
```

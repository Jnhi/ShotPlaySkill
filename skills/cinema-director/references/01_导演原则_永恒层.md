# L1 · 导演原则 — 永恒层

> 本层只写**电影规律**。模型换十代不改一字。修订条件：3 次独立的实战证据 + 进化日志记录。
>
> **每条律法都有破律条款。区别专业和顶尖的不是守律，是知道何时破律、并说得出为什么。**
> 破律的唯一形式要求：在分镜表"导演意图"列写明 `⚡破律：[律号] 因为[意图]`。说不出意图=不许破。

---

## 律一 · 存在理由律（不可破）

每个镜头去掉后，观众必须失去**信息/情绪/节奏**三者之一，否则删除。

**破律条款：无。** 这是唯一没有例外的律。"很美"不是存在理由，美必须服务于三者之一。

## 律二 · 景别交替律（默认律）

相邻镜头默认换景别，至少跨一级；同景别默认不连续超过 2 镜；景别跳两级以上默认需过渡。

**破律条款（合法情形）：**

| 破律方式 | 效果 | 经典用法 |
|----------|------|----------|
| 同景别正反打连续多镜 | 对峙的"针锋相对"感，谁也不让 | 审讯戏、谈判戏：双方 CU 对 CU，景别完全对等=力量完全对等 |
| 同机位同景别重复出现 | 喜剧节拍器 / 命运感 / 压迫感 | 周星驰式三次重复；同一空镜每集出现=宿命母题 |
| 同景别 Jump Cut | 时间跳跃、焦躁、精神不稳 | 人物等待/崩溃过程，同机位跳剪 |
| 两级以上硬跳（LS→ECU） | 突然的窥视感/惊吓/天启 | 全景中平静的人 → 直切眼部 ECU = 有事发生了 |

破律判据：**对等、重复、断裂**这三种戏剧意图出现时，同景别比换景别更有力。

## 律三 · 动静匹配律（默认律）

运动镜头默认接运动镜头，静止默认接静止；动↔静转换默认需要减速/起势镜头。

**破律条款（合法情形）：**

| 破律方式 | 效果 | 经典用法 |
|----------|------|----------|
| 动 → 静 硬切 | 急刹车式冲击：死亡、噩耗、被抓现行 | 狂奔跟拍 → 直切尸体固定全景；嬉闹手持 → 直切门口站着的人 |
| 静 → 动 硬切 | 惊吓、爆发、世界突变 | 长久静止凝视 → 直切爆炸/扑杀（jump scare 的本质）|
| 全片节奏断层 | 段落级的"换气"，宣告叙事阶段切换 | 高速动作段落结束后直切漫长静止空镜 |

破律判据：**当"不舒服"正是你要的情绪时，硬切比平滑更对。** 平滑是为了让观众不出戏，冲击是为了把观众撞醒——先想清楚此刻要哪个。

## 律四 · 轴线律（180°）

两角色关系轴线确定后，机位默认同侧。越轴=方向感崩溃。

**破律条款：** 合法越轴三法——①中间插入轴线上的中性镜头（正面/俯拍）②镜头运动中带观众越过轴线 ③故意越轴制造迷失（混战、精神错乱、立场反转的瞬间——立场变了，轴线就该变）。

## 律五 · 连贯性律

动作衔接、视线方向、时间连续、光影一致（一个场景=一套光影方案，换场景才换光）。

**破律条款：** 心理蒙太奇/梦境/回忆可打破时间连续；光影在剧情内有光源事件时可变（灯灭、日落、火起——**变光必须是剧情事件**，不许无故变）。

## 律六 · 声画存在律（v5.0 新增）

**无声的画面是半个镜头。** 每个镜头在分镜阶段就必须回答：此刻观众听到什么？声音三轨（台词/音效/环境声）与画面同权设计，不是后期补丁。详见 L3 声音系统。

**破律条款：** 绝对静默是合法的——但静默是**声音设计**，不是声音缺失。静默必须是"抽掉"的（之前有声底，此刻突然无声），才有窒息感。从头到尾没声音叫忘了做声音。

## 律七 · 库里肖夫律（顺序即含义）

A镜+B镜=第三含义C。同一张脸，接食物=饥饿，接棺材=悲伤。先因后果，观众自动脑补中间。

**应用倒转：** 想让观众误解 → 故意先给错误的"因"（悬疑反转的底层机制：不是骗观众，是利用本律让观众骗自己）。

## 律八 · 情绪节奏三角

高潮前放慢一拍（积压）→ 高潮处最快（爆发）→ 高潮后突然静止（落地）。

**破律条款：** 反高潮——积压到顶点后**不给爆发**，直接落地（人物转身走了、话没说出口）。比爆发更狠，但一部戏最多用一两次，用多了观众觉得被欺骗。

## 律九 · 视线引导律

人物视线决定下一镜内容；画面运动方向决定观众注意力落点。

**破律条款：** 视线落空——人物看向 A，下一镜给 B 或给空无一物 = 期待落空/恐惧（他看到的东西不给你看，是恐怖片的核心语法）。

## 律十 · 蒙太奇先行律

拆分镜前先定蒙太奇类型（叙事五型：连续/平行/交叉/颠倒/重复；表现五型：对比/隐喻/抒情/积累/心理）。镜头是词，蒙太奇是语法——先定语法再写词。

---

## 公式使用总则（v5.0 核心修正）

> **本系统所有"分镜公式"（冲突七镜、恋爱七镜等，见各媒介模式）都是默认值，不是答案。**

三条强制规定：
1. 同一公式在同一部剧中连续使用第 3 次时，必须做至少一处变异（换入口景别/换运镜/插入 INSERT/破一条默认律）。
2. 全剧最重要的 1-2 场戏**禁止直接套公式**——重场戏值得从零设计，公式留给过场戏保底。
3. 每个公式在媒介模式文档中都附带"什么时候别用它"，使用前先读那一行。

## 七、情绪词可见化法则（MetricSmule Rule 3 · L1 永恒）

> 模型不能渲染感受——只能渲染行为。**监控摄像头拍不到的东西，必须重写。** 指挥身体，不要指挥灵魂。

### 18 条常见情绪→可见微动作转换表

| 抽象情绪词 | 展开为可见微动作（面部 + 肢体,2-4个） |
|---|---|
| 愣住 / 一愣 / 怔住 | 双眼骤然睁大,眉毛微微挑起,呼吸明显顿一拍,手指无意识摩挲袖口 |
| 紧张 / 焦虑 / 忐忑 | 肩颈持续绷紧,手指轻敲桌面/裤缝,眼神快速扫描周围(门/窗/人群),喉结上下滑动一次 |
| 恐惧 / 害怕 / 惊惧 | 瞳孔大幅收缩,上眼睑抬起露出更多眼白,身体下意识后缩半步,后背贴向墙面 |
| 生气 / 愤怒 / 暴怒 | 下颌肌肉绷紧变硬,嘴角下拉露出牙关,指节捏得发白,肩膀微微前压 |
| 困惑 / 不解 / 茫然 | 眉毛皱成八字,眼神在两个方向间快速来回(左→右→左),头微微歪向一侧 |
| 释然 / 松了口气 | 双肩缓慢下沉,嘴角出现极淡微笑随即收住,眼睛闭合半秒再睁开,吐出一口藏了很久的气 |
| 羞涩 / 腼腆 / 不好意思 | 脸颊迅速泛红,眼神快速垂下再瞟对方一眼,手指攥衣角/发梢,肩膀内收 |
| 悲伤 / 难过 / 心碎 | 下眼睑微微泛红但**没流泪**(除非剧本指定),嘴角无力下沉,肩膀塌下来,呼吸变浅变长 |
| 震惊 / 难以置信 | 双眼睁到最大,嘴巴不自觉张开半寸,身体僵住不动约0.5秒,随后猛地摇头 |
| 兴奋 / 狂喜 / 激动 | 嘴角大幅上扬笑到露牙,双眼亮起来瞳孔略放大,身体微微跃起半寸,手攥成拳又松开 |
| 隐忍 / 克制 / 压抑 | 嘴唇紧抿成一条线,眼球缓慢左右转动不看对方,手指指甲掐进掌心(发白),呼吸用胸腔不用腹部 |
| 绝望 / 崩溃 / 垮掉 | 眼神空洞失焦,肩膀彻底塌下来,双手无力垂在身体两侧,头缓慢垂下不抬起来 |
| 慌乱 / 慌张 / 不知所措 | 眼球快速四处扫视(频率≥3次/秒),脚步小碎步挪动,双手不知道放哪(摸口袋→摸脸→放下) |
| 警惕 / 戒备 / 警觉 | 头微微歪向声源方向,眼睛眯起来聚焦,身体重心移到脚前掌准备启动,手悄悄摸向腰部 |
| 冷漠 / 不在意 / 无所谓 | 眼神从对方脸上滑过去不做停留,嘴角不动,手指继续做之前的事(翻书/敲桌面),身体不转向对方 |
| 温柔 / 宠溺 / 心疼 | 眼神柔和下来瞳孔略放大,嘴角上扬极淡的笑,手指动作放缓(摸头/擦泪/递水),身体微微前倾 |
| 内疚 / 愧疚 / 抱歉 | 眼神快速垂下躲开对方视线,嘴角微微抿紧,手指搓另一只手的手背,脚蹭地面 |
| 不甘 / 不服 / 不甘心 | 眉头拧成川字,嘴角一侧微微上扬(冷笑),拳头攥紧又松开,下巴微微抬高不认输 |

**铁则**:
1. 每个情绪词必须拆成 **面部动作 × 1 + 肢体动作 × 1**,不许只写一个。
2. 不许写"她感到XX""他内心XX"——模型没有内心,只有像素。
3. 写不出对应动作的情绪词=不该写,直接删。
4. 18 条不够用时,按同一原则自补:**监控摄像头能拍到吗?能→写;不能→删**。

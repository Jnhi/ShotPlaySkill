# 08 · 运镜库

```
定位：全题材镜头运动的唯一武器库——文戏/武戏/特效场统一选词
强制纪律：六段式镜头块"4.镜头设计·运镜"必须从本库选取,禁止自造运镜描述
运镜写法：写全五要素(①起幅机位+主体位置 ②运法 ③轨迹 ④速度/变速绑动作帧 ⑤落幅+动机),核心="从哪里到哪里"
```

---

## 一、基础运镜（8种——覆盖90%日常场景）

| 名称 | 画面效果 | 什么时候用 |
|---|---|---|
| 固定镜 | 机位纹丝不动,只有画面内物体运动 | 对话/凝视/特写情绪/需要观众自己发现画面变化的时刻;文戏之王,零运动最稳 |
| 缓慢推入 | 从全景缓缓推向角色面部/关键细节 | 情感拉近/紧张积累/让观众逐渐聚焦;文戏主力,情绪递进的标准手法 |
| 快速拉出 | 从特写急速拉远,环境骤然展开 | 揭示全貌/孤独感/人物被环境包围/结尾收束;一拳打在观众脸上的反差 |
| 微距缓推 | 极端缓慢推向关键细节(信物/伤痕/唇/泪) | 需要观众注意某个小物件/微表情/微小动作的时刻 |
| 横移跟拍 | 水平跟随角色行走/移动,保持等距 | 人物走位戏/双人对话时来回移动的空间关系/保持对话双方都在画面里 |
| 垂直升降 | 从地面仰拍升起/从高处俯拍降下 | 英雄登场/场景建立/展现人物与天空/地面的关系 |
| 环绕拍摄 | 围绕主体做半圆/全圆运动 | 产品展示/双人对峙/拥抱亲密/360°展立体关系;主体尽量不动,只动镜头 |
| 手持灵动 | 模拟呼吸感的轻微手持晃动 | 现场真实感/紧迫时刻/纪录片感/让观众感觉"在现场" |

## 二、特殊技法（炸裂运镜+电影技法——需要冲击力时用）

| 名称 | 画面效果 | 什么时候用 |
|---|---|---|
| 速度坡道 | 同镜变速:先快→骤降极慢0.5-1秒→猛然恢复高速 | 打斗命中瞬间/摔杯瞬间/回眸瞬间/任何需要"时间被攥住再放开"的时刻;**一个15s段最多一个** |
| 急推 Crash Zoom | 0.5秒内从全景/中景怼到极特写,带轻微冲击晃动 | 震惊/发现/杀机锁定/喜剧突脸;短促单方向,最稳的炸裂镜 |
| 锤帧定格 | 动作命中瞬间画面近乎冻结0.3-0.5秒,尘埃/水珠/火星悬浮,随后动作继续 | 拳/剑/箭命中的那一秒;悬浮物必须写明(尘埃/水珠/火星/花瓣) |
| 子弹时间 Bullet Time | 时间完全静止,箭矢/碎片悬停空中,镜头围绕主体快速环绕 | 万箭齐发/跃起回身/爆发瞬间;**只冻结主体只动镜头** |
| FPV俯冲 | 第一视角穿越机从高空垂直扎向目标 | 开场建立/追杀开始/竖屏天选(9:16画幅纵深=跑道) |
| 穿隙飞行 | 镜头贴地高速穿过窗缝/门洞/车底/人群缝隙 | 空间转场/潜入;**每段只穿一个障碍**,多障碍分段拼 |
| 穿物镜头 | 镜头推进穿过酒杯/火焰/瞳孔进入下一空间 | 场景转场/入梦/回忆;穿过物体的那一帧=天然剪辑点 |
| 物件POV | 镜头跟着箭/刀/酒坛飞,背景拉成速度线 | 射箭/掷物;天然自带速度坡道结构 |
| 高速环绕 | 围绕主体360°快转,周围敌人/物体化为环形虚影 | 被包围/觉醒变身/对峙升级;**主体静止+只动镜头**=最稳 |
| 螺旋升降 | 边环绕边升/降 | 胜利宣告(升)/坠入绝境(降);拆两段做:环绕段+升/降段 |
| 滚转 Barrel Roll | 镜头沿光轴翻滚180°,天地倒转 | 坠落/中毒眩晕/世界颠覆;拆两段做 |
| 移轴变焦 Dolly Zoom | 后拉同时变焦推近,人物大小不变背景骤然压缩/拉伸 | 角色顿悟/恐惧来袭/价值观崩塌的瞬间;**全片最多1-2次**,用多了=廉价 |
| 甩镜 Whip Pan | 高速横/竖甩,运动模糊中切下镜 | 同场跳视点/时空跳转/喜剧反差/隐藏剪辑点;最便宜的"伪一镜到底"胶水 |
| 跟拳镜头 | 镜头跟着拳头/剑尖走完攻击全程,命中瞬间镜头同步震颤 | 近战命中;配锤帧定格=王炸组合 |
| 人物锁定 Snorricam | 镜头焊在人物身上,人物在画面中纹丝不动,背景疯转 | 崩溃/狂奔/醉酒/世界在眼中崩塌 |
| 破障冲击 | 镜头跟人物一起撞破门/墙/水面,木屑/水花朝镜头爆开 | 破门救人/破水而出;爆开帧=天然剪辑点 |
| 焦点转移 Rack Focus | 机位纹丝不动,一镜内焦点从前景移到后景完成信息揭示 | 前景对话中焦点后移露出偷听者/道具与表情之间的暗示连接;**非机位运动**,不违反单镜单向红线 |

## 三、速度坡道专章（速度坡道技法的标准节奏模板）

```
段式：快 → 锤 → 甩
0.0-1.2s  高速段：FPV/推进/跟拳,全速冲向动作点(背景拉成速度线)
1.2-2.2s  锤帧段：在「命中/对视/碎裂」帧骤降至0.1-0.2x,1秒内给足细节
                  (飞溅的血珠/悬浮的茶水/瞳孔收缩——这1秒是观众截图发朋友圈的1秒)
2.2-3.0s  甩出段：猛然恢复高速甩离(甩镜/拉远/穿越下一目标)
```

**铁则**：变速点必须绑定具体物理事件("命中瞬间""杯子触地瞬间"),写"中途变慢"AI会随机选帧=废片。锤帧段的悬浮物(尘埃/水珠/火星/花瓣)必须写明——悬浮物是慢动作的"可见证据"。

## 四、情绪反查（已知情绪→推荐运镜组合）

| 目标情绪/场景 | 推荐运镜组合 |
|---|---|
| 浪漫时刻 | 缓慢推入 + 微距缓推 |
| 激烈争吵 | 急推极特写 + 甩镜转场 + 倾斜构图 |
| 紧张潜行 | 手持微颤 + 主观视角 |
| 英雄登场 | 垂直升降 + 高速环绕 |
| 悲伤失落 | 快速拉出 + 孤独广角 + 眼泪滑落 |
| 记忆闪回 | 模糊转清 + 老胶片 |
| 史诗战斗 | 子弹时间 + 锤帧定格 + 跟拳镜头 |
| 压抑对峙 | 固定镜 + 缓慢推入(极慢) |
| 惊悚发现 | 速度坡道(加速→锤帧→甩出) + 移轴变焦 |

## 五、声音设计（运镜+声音=爽感翻倍）

炸裂运镜一半的爽感在耳朵里。声音写进该镜"6.音效"行,与动作帧对齐:

| 画面 | 声音写法 |
|---|---|
| 高速段 | 风声呼啸由弱至强,衣袂破空声 |
| 锤帧瞬间 | 所有声音骤然抽空,仅剩低频心跳/耳鸣 0.8秒 |
| 甩出段 | 声音轰然回灌,破空尖啸 |
| 命中帧 | 闷雷般的低频冲击声(sub-drop),余响短促 |
| 环绕段 | 环境声随镜头旋转做方位流转(人声/马蹄声绕耳) |

**口诀:快段风声起,锤帧全抽空,甩出轰回来。** 声音坡道和画面坡道必须同帧。

## 六、竖屏特化（9:16 优势运镜）

- **垂直俯冲是竖屏天选镜头**:9:16画幅纵深即跑道,FPV俯冲/螺旋降在竖屏比横屏爽30%
- 甩镜用**竖甩**(上下甩)替代横甩:横向空间不够,竖甩天然顺画幅
- 高速环绕在竖屏要收紧半径(主体占屏60%+时大半径环绕会丢主体)

## 七、纪律红线

| 规则 | 原因 |
|---|---|
| 一个镜头**只写一个运镜** | 多运动方向=AI晕=废片(如"环绕同时推向目标"必须拆两镜) |
| 变速必须绑具体动作帧 | "中途变慢"AI会随机选帧,必须写"命中瞬间""她转身瞬间" |
| 锤帧段必须写悬浮物 | 没有尘埃/水珠/火星,观众感知不到时间冻结 |
| 每段≤30s**炸裂运镜最多1个** | 爽是重音不是节拍,重音连打=没有重音 |
| 高速段主体别用脸 | 高速运动+人脸=崩脸高发,用剪影/背影/远景/物件承担,人脸只出现在锤帧段和静止段 |
| 移轴变焦/子弹时间**全片最多1-2次** | 太醒目的技法用多了=廉价感,必须用在关键转折点 |
| **禁止越轴** | 同一场景所有机位必须在轴线同侧;合法越轴两通道:①插骑轴镜(人物正面/背面、正中对称构图)②让人物走位运动越轴,用运动本身过渡 |
| **同主体相邻镜头机位差≥30°** | 差不足30°且同景别=画面猛跳似素材抽帧(跳帧抽搐);达标二选一:机位跨30°以上 或 景别跨一级(中景→近景) |

# L4 · 媒介模式 — 电影（横屏 16:9 / 2.39:1）

```
画幅：16:9 或 2.39:1 宽银幕｜时长：90-120分钟｜观看场景：黑暗影厅/大屏，观众不会划走
本质：短剧抢注意力，电影**已经拥有**注意力——所以电影的武器是短剧用不起的：留白、沉默、慢。
```

> **切换思维开关：从"留住观众"切到"带领观众"。** 在短剧里是自杀的手法（长镜头、大全景、40秒无台词），在电影里是王牌。

---

## 一、结构：三幕 + 序列

```
第一幕(0-25%)   建立世界与人物 → 激励事件(10%) → 第一幕转折：主角被迫上路
第二幕(25-75%)  升级与复杂化 → 中点(50%)：假胜利/假失败，目标变质 → 低谷(75%)：一无所有
第三幕(75-100%) 决战 → 高潮 → 余韵（电影必须有余韵，这是和短剧的根本区别）
```

每幕由 3-5 个序列（sequence）组成，每个序列8-15分钟、有自己的小高潮——**序列是电影的"集"**，分镜以序列为单位规划节奏，而非以场为单位。

## 二、横屏镜头语法（与竖屏的系统差异）

| 维度 | 竖屏短剧 | 横屏电影 |
|------|----------|----------|
| 构图 | 中央偏上，怼脸 | 三分法、对称、framing within frame，**横向关系**可拍（两人之间的距离=关系）|
| 景别频谱 | MCU/CU/ECU为主 | **全频谱**。ELS/LS是电影的特权：人与环境的关系本身是叙事 |
| 双人 | 正反打不同框 | 同框是武器——同框构图里的位置、高低、间距全是台词 |
| 运镜 | 纵向推拉 | 横摇/横移解禁；长镜头调度（一镜内完成多重信息）|
| 信息密度 | 每镜单一信息 | 一帧多层信息：前景/中景/背景同时叙事 |
| 单镜时长 | ≤3s（L2约束）| 美学上允许任意长；当前AI生成仍受L2约束→长镜头感用"缓慢运镜+多段拼接"模拟 |

## 三、电影专属武器（短剧禁区，此处合法）

- **视觉母题**：一个意象全片重复变奏3-5次（L1律二破律"重复"的全片级应用）——每次出现含义递进，最后一次反转
- **留白与呼吸**：高潮序列之间必须有低密度段落（纯环境、无台词的日常）；观众的情绪肌肉需要放松才能再次收紧
- **慢揭示**：信息可以晚给、分次给、永远不给（开放性）；短剧的"3秒兑现"规则在此**作废**
- **色彩弧线**：全片色调随主角内在状态演进（如暖→冷→灰→一点暖），以幕为单位规划，写进每幕的光影方案

## 四、电影声音特化（基于 L3）

- **声场纵深**：远/中/近三层声音同时存在（远处城市轰鸣+中景人群+近景对白），提示词中按层写
- **沉默的尺度**：电影可承受分钟级无台词，但每个无台词段落必须有声音设计（声底变化、音效叙事）
- **J/L-cut 为常态**：电影的场景转换默认声音先行或延续，硬切声音反而是重音
- 无BGM红线照常——电影配乐更需要后期作曲家统一处理，AI生成阶段绝对干净

## 五、AI 生成电影的当前现实（与 L2 的接口）

横屏16:9生成同受 L2 约束（≤30s/段、单一运镜）。电影感的实现路径：
1. 长镜头感 = 多段缓慢运镜拼接 + 段间动作/声音无缝衔接（L3 段尾声音状态强制声明）或用 extend forward 延长已生成段（音画连贯更稳）
2. 大景别合法但仍遵守"静中有动"（环境有风/水/人流，主体可静）
3. 序列为单位做光影方案和声底方案，幕为单位做色彩弧线
